## 1. 주간 기록

### 0주차 — 주제 선정
- **결정**: 자율 주제 중 "내 공부 자료 기반 AI 학습 튜터(StudyMate AI)"
- **선정 기준과 판단**

| 기준 | 판단 |
|---|---|
| 테스터 5명 이상 확보가 쉬운가 | ✅ 같은 과정 동료·친구 누구나 자기 자료로 바로 사용 가능. 자료가 없으면 샘플 제공 |
| 팀이 데이터를 따로 모아야 하나 | ✅ 아니오. 사용자가 자기 자료를 올림 |
| 필수 기술 요소 2개 이상이 자연스럽게 들어가나 | ✅ Agent + RAG + Long-term Memory (+ n8n 자동화) |
| 4주 안에 배포·테스트·개선까지 가능한가 | ✅ Streamlit 단일 앱, 무료 배포 |
