## 1단계. OpenAI API 키 발급
1. platform.openai.com 접속 → 로그인
2. **Settings → Billing**: 결제 수단 등록 후 크레딧 충전 (최소 금액, 예: $5~10)
3. **Settings → Limits(또는 Usage limits)**: 월 사용 한도를 충전 금액 수준으로 설정 → 예상치 못한 과금 방지
4. **API keys → Create new secret key** → 이름 `studymate` → 생성된 `sk-...` 키를 **바로 복사해 안전한 곳에 저장** (다시 볼 수 없음)
5. ⚠️ 키는 절대 코드·GitHub·단톡방에 올리지 않습니다. `.env`(로컬)와 Streamlit Secrets(배포)에만 넣습니다.

## 2단계. 내 컴퓨터에서 실행
### 2-1. Python 설치
- python.org → Downloads → **Python 3.12.x** 설치
- Windows: 설치 첫 화면에서 **"Add python.exe to PATH" 체크** 필수
- 확인: 터미널(Windows는 PowerShell)에서 `python --version` (mac은 `python3 --version`)

### 2-2. 프로젝트 준비
1. 받은 `studymate-ai` 폴더를 원하는 위치에 압축 해제
2. VS Code로 폴더 열기 → 상단 메뉴 **Terminal → New Terminal**

### 2-3. 가상환경·패키지 설치
```bash
# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```
> PowerShell에서 "스크립트를 실행할 수 없습니다" 오류가 나면: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 실행 후 다시 시도

### 2-4. 환경 변수 파일 만들기
```bash
# Windows
copy .env.example .env
# macOS / Linux
cp .env.example .env
```
`.env`를 열어 `OPENAI_API_KEY=sk-...`에 1단계 키를 넣고, `ADMIN_PASSWORD`를 팀만 아는 값으로 바꿉니다. (DB는 기본값 SQLite 그대로 두면 `data/` 폴더에 자동 생성)

### 2-5. 테스트 → 실행
```bash
pytest -q                 # 57 passed 가 나오면 정상 (API 키 없이도 통과)
streamlit run app.py      # 브라우저에서 http://localhost:8501 자동 열림
```
### 2-6. 동작 확인
가입(동의 체크) → 📚 내 자료 → **샘플 자료 넣기** → 💬 AI 튜터에서 "임베딩이 뭐야?" → 답변에 [S1]과 '근거 자료'가 보이면 성공 → 📝 퀴즈 5문항 → 🧠 학습 기록에서 약점 확인

## 3단계. GitHub 저장소
### 3-1. 저장소 만들기 (PM 1명)
1. github.com → 오른쪽 위 **+ → New repository**
2. Repository name: `studymate-ai` / Public 권장(포트폴리오) / **README·.gitignore 추가하지 않음**(이미 있음) → Create

### 3-2. 첫 push
```bash
git init
git status                         # ⚠️ .env, data/ 가 목록에 없어야 함 (.gitignore가 막아 줌)
git add .
git commit -m "chore: 프로젝트 초기 구조와 문서 추가"
git branch -M main
git remote add origin https://github.com/<아이디>/studymate-ai.git
git push -u origin main
```
> 처음 push할 때 로그인 창이 뜨면 GitHub 계정으로 인증합니다.

### 3-3. 팀 협업 설정
1. 저장소 **Settings → Collaborators → Add people** → 팀원 GitHub 아이디 초대 (팀원은 메일에서 수락)
2. **Settings → Branches(또는 Rules → Rulesets)** → `main` 보호 규칙: "Pull request 필수", "Status check(CI) 통과 필수"
3. **Issues → Labels**에 `feature`, `bug`, `feedback`, `docs` 라벨 확인/추가
4. **Projects → New project → Board**: `Todo / In Progress / Review / Done` 칸 → 이슈를 카드로 관리
5. `docs/09_Git_협업_가이드.md`의 브랜치·커밋 규칙을 팀 전원이 읽기
6. 팀원: `git clone https://github.com/<아이디>/studymate-ai.git` → 2-3, 2-4단계 반복

## 4단계. Supabase DB (배포 시 데이터가 사라지지 않게)
> Streamlit Cloud는 재시작하면 파일이 초기화됩니다. DB를 Supabase에 두어야 **장기 기억이 유지**됩니다.

1. supabase.com → **Start your project** → GitHub로 로그인
2. **New project**: 이름 `studymate` / Database Password: **영문+숫자로 긴 비밀번호**(특수문자는 주소 오류를 일으킬 수 있어 피함) → 따로 저장 / Region: **Northeast Asia (Seoul)** → Create
3. 2분 정도 기다린 뒤 프로젝트 상단의 **Connect** 버튼 → Connection string → **Transaction pooler** 의 URI 복사
   - 형태: `postgresql://postgres.<프로젝트ID>:[YOUR-PASSWORD]@aws-…-ap-northeast-2.pooler.supabase.com:6543/postgres`
   - `[YOUR-PASSWORD]`를 2번 비밀번호로 바꿉니다. (대괄호도 지움)
   - ⚠️ Direct connection이 아니라 **pooler** 주소를 써야 Streamlit Cloud에서 접속됩니다.
4. (로컬 확인) `.env`의 `DATABASE_URL`을 이 주소로 바꾸고 `streamlit run app.py` → 가입 → Supabase **Table Editor**에 `users` 등 8개 테이블과 가입한 행이 보이면 성공 (테이블은 앱이 처음 실행될 때 자동 생성)
5. 확인 후 로컬 개발은 다시 SQLite로 돌려도 됩니다.

> 무료 프로젝트는 오래 사용하지 않으면 일시 중지될 수 있습니다. 대시보드에서 **Restore**를 누르면 다시 켜집니다. 테스트 기간에는 매일 접속 확인하세요.

## 5단계. Streamlit Community Cloud 배포
1. share.streamlit.io → **Continue with GitHub** → 권한 승인 (비공개 저장소면 비공개 저장소 접근도 허용)
2. **Create app** → GitHub 저장소에서 배포 선택
   - Repository: `<아이디>/studymate-ai`
   - Branch: `main`
   - Main file path: `app.py`
   - App URL: 원하는 주소 (예: `studymate-ai-team1`)
3. **Advanced settings**
   - Python version: **3.12**
   - Secrets: `.streamlit/secrets.toml.example` 내용을 복사해 붙여 넣고 실제 값으로 바꿈
     ```toml
     OPENAI_API_KEY = "sk-..."
     DATABASE_URL = "postgresql://postgres.xxxx:비밀번호@...pooler.supabase.com:6543/postgres"
     ADMIN_PASSWORD = "팀만-아는-긴-비밀번호"
     DATA_RETENTION_UNTIL = "2027년 1월 31일"
     ```
4. **Deploy** → 몇 분간 설치 로그가 흐른 뒤 앱이 열리면 완료
5. 이후 `main`에 push하면 **자동으로 재배포**됩니다. Secrets 수정은 앱 화면 오른쪽 아래 **Manage app → ⋮ → Settings → Secrets**
6. 배포 URL을 README의 "링크"와 발표 자료에 기록

> 일정 시간 아무도 접속하지 않으면 앱이 잠자기 상태가 됩니다. 접속 시 나오는 깨우기 버튼을 누르면 잠시 후 다시 켜집니다. 데이터는 Supabase에 있으므로 사라지지 않습니다.

## 문제 해결 (FAQ)

| 증상 | 원인 / 해결 |
|---|---|
| `ModuleNotFoundError: No module named 'studymate'` | 프로젝트 최상위 폴더(app.py가 있는 곳)에서 실행했는지 확인 |
